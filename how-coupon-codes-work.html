How coupon codes actually work

Why one code applies to a basket and another does not, and what the small print controls.

A code is a set of conditions

Behind each code is a rule: a minimum spend, included or excluded categories, a validity window, a usage limit, and often a first-order requirement.

Why a working code fails

  • The basket is below the minimum spend.
  • One item is excluded from the promotion.
  • The code expired or hit its usage limit.
  • Another offer in the basket cannot be combined with it.

Order of application

Discounts are applied in a fixed order and a later one is often calculated on the reduced total. That is why two codes can give less than expected, and why the checkout total is the only figure that matters.

How to use a code properly

  1. Read the conditions first.
  2. Meet the minimum spend on the right subtotal.
  3. Confirm which items are included.
  4. Check the total after it applies.

The habit that saves most

If the code is the only reason you are buying, pause. A code that shrinks an unplanned purchase is still an unplanned spend.
